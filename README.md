# Tanmay Sahoo — Academic Website

Static academic website prepared for GitHub Pages.

## Structure

- `index.html` — homepage
- `research.html` — research programme and themes
- `publications.html` — journal articles, preprints, and ongoing work
- `teaching.html` — courses and teaching experience
- `talks-service.html` — talks, conferences, reviewing, and honours
- `styles.css` — site styling
- `site.js` — small progressive-enhancement script

## Publishing

Create a public repository named `<github-username>.github.io`, place these files
at its root, and enable GitHub Pages from the `main` branch.

The site has no build dependencies and can be served directly by GitHub Pages.
